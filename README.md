# mapaf-offline-data — بستهٔ دادهٔ آفلاین مسیریاب مستقل افغانستان

داده‌های کامل نقشهٔ افغانستان برای اپلیکیشن **Map.af Navigation** (`mapaf-android`).
منشأ داده: نقشهٔ منتشرشدهٔ map.af (پایهٔ OpenStreetMap).

## دریافت توسط اپلیکیشن
در برنامه: **تنظیمات ← نشانی بستهٔ داده** و این نشانی را وارد کنید:
```
https://github.com/kazemwafa2/mapaf-offline-data/releases/download/v1.0
```
سپس: **مدیریت آفلاین ← دانلود بسته**. برنامه `MANIFEST.json` را می‌خواند،
هر فایل را دانلود و SHA-256 آن را قبل از نصب تأیید می‌کند.

## فایل‌های بستهٔ Release v1.0
| فایل | حجم | نقش |
|---|---|---|
| af.pmtiles | ۱۳۶MB | کل نقشهٔ کشور (تیل‌های برداری، زوم ۰–۱۴) |
| routing_graph.bin | ۵۸MB | گراف مسیریابی (۲.۳ میلیون گره، ۳.۱ میلیون یال) |
| search_index.db | ۱۴.۶MB | ایندکس جستجوی فارسی/انگلیسی |
| registered_places.db | ۱۳۱KB | مکان‌های ثبت‌شدهٔ کاربران |
| provinces.geojson | ۱۷۸KB | مرز ۳۴ ولایت |
| postal_codes.json | ۱۵۵KB | کدهای پستی |
| places.json | ۵.۲MB | فهرست مکان‌ها |
| summary.json | ۲KB | خلاصهٔ آماری |
| MANIFEST.json | ۲KB | نسخه، سایز و SHA-256 همهٔ فایل‌ها |

فایل‌های کوچک (MANIFEST، ولایت‌ها، کد پستی، مکان‌ها، summary) در همین
مخزن هم به‌عنوان نسخهٔ پشتیبان commit شده‌اند؛ فایل‌های بزرگ فقط در Release هستند.
